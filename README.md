# gestao-pessoas

Software de Gestão de Pessoas (RH) da COONTROL. Next.js (App Router) + Supabase (schema `rh`) + Tailwind CSS + shadcn/ui.

Especificação completa do projeto: [CLAUDE.md](./CLAUDE.md).
Protótipo HTML original (referência de UX): [docs/coontrol-rh-prototipo.html](./docs/coontrol-rh-prototipo.html).

## Desenvolvimento

```bash
npm install
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000).

## Banco de dados

Migrations em `supabase/migrations`, aplicadas ao projeto Supabase `coontrol-prod` (schema `rh`).
